# Frontend para Gestión de Tareas

Aplicación de Gestión de tareas con:

- React (Vite)
- Bootstrap (estilos)
- Fetch API (conexión al backend)

## Configuración

1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Crea un archivo `.env` con VITE_API_URL = http://localhost:3000/api
4. Ejecuta `npm run dev` para iniciar el servidor.

## Estructura

- TaskList.jsx → Muestra todas las tareas
- TaskForm.jsx → Formulario CRUD
- TaskItem.jsx → Tarea individual
