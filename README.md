# Challenge ForIT - Gestión de Tareas App

Aplicación completa de gestión de tareas con backend en Node.js/Express y frontend en React.

## Instalación y Ejecución

1. Clonar el repositorio:
    git clone https://github.com/tu-usuario/challenge-forIT.git
    cd challenge-forIT

2. Ejecutar el script de inicialización, soporta tanto Linux como Windows (vía Git Bash):
    chmod +x init.sh
    ./init.sh

3. Acceder a la aplicación 
    Backend: http://localhost:3000
    Frontend: http://localhost:5173

## Tecnologías Utilizadas

### Backend
    Node.js
    Express
    SQLite

### Frontend
    React
    Vite
    Bootstrap 5
    React Router
